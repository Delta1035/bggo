# BGGo 文档

这套文档描述 BGGo 当前能力、开发方式和从 Alpha 走向公开发布所需的工作。代码和文档不一致时，以已发布版本的代码行为为准，并在修复行为的同时更新对应文档。

## 阅读路径

| 读者 | 建议从这里开始 |
| --- | --- |
| 普通用户和测试者 | [用户指南与故障排查](user-guide.md) |
| 新加入的开发者 | [架构说明](architecture.md) → [开发指南](development.md) |
| 发布负责人 | [发布与更新方案](release-and-update.md) |

## 文档维护约定

- 新增用户可见功能时，同时更新产品范围和用户指南。
- 修改配置文件、系统命令、权限或数据目录时，同时更新架构和故障排查。
- 修改构建、版本或发布流程时，同时更新开发指南和发布方案。
- 完成任务卡时，在合并前补齐验收记录，不只勾选任务标题。
- 网站可以复用这里的内容，但网站技术栈必须由项目负责人确认后再创建。
